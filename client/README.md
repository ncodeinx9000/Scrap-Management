# Client setup

From the project root, install and run the Vite app:

```powershell
cd client
npm install
```

Set `client/.env` to:

```dotenv
VITE_API_URL=http://localhost:5000/api
```

Then start the development server:

```powershell
npm run dev
```

See the [project README](../README.md) for API and MongoDB setup.
